# Chapter 7 — A dynamic factor model with time-varying parameters and stochastic volatility

*Handbook Chapter 7: the Mumtaz–Surico model — a panel of series driven
by a world factor and country factors, each factor an AR(2) with
time-varying coefficients and stochastic volatility, the idiosyncratic
components AR(1) with stochastic volatility; priors and the Gibbs
algorithm (§3, `example1.m`) on data generated by `generate_data.m`
(`dataxx01.mat`: 80 series, four countries, 220 periods).*

Spec: `examples/handbook/ch7_dfm_sv` (built by `build_ch7.py` from the
handbook's `.mat` file, the first two countries: 40 series).

## 1. The model

    x_it = λ^w_i F^w_t + λ^c_i F^{c(i)}_t + e_it
    F_t  = α_t + ρ_{1,t} F_{t−1} + ρ_{2,t} F_{t−2} + u_t,      Var(u_t) = exp(h^F_t)
    e_it = φ_{i,t} e_{i,t−1} + v_it,                          Var(v_it) = exp(h_i,t)

with every coefficient a random walk and every log-variance a random
walk. The Gibbs sampler (§3) draws the factors by Carter–Kohn given
everything else, the time-varying coefficients by Carter–Kohn given the
factors, the volatilities by the JPR step, the loadings by regression —
a large cycle, 20,000 sweeps with a training sample for the priors.

## 2. Where the toolkit's class ends

Three of the model's four ingredients are in the class today:

- **Factors as states with static loadings** — Chapter 3 §6 (the DFM
  block), any number of factors.
- **Stochastic volatility on state shocks** — the SV block through the
  time-varying `Q_t` (stage S6), one log-variance random walk per factor
  shock.
- **Time-varying coefficients on observed regressors** — E4 (stage S9).

The fourth is not: **time-varying AR coefficients on a latent factor**.
`ρ_t F_{t−1}` is a product of two states, and conditional on the
coefficient *paths* the system is linear with a time-varying transition
matrix `F_t` — the same conditioning trick the SV block uses, but on `F`
rather than on `Q`. That is extension E6: the `Z_t` playbook applied to
the transition matrix (an `array[] matrix F` core in the shared filter,
the Python mirror, a constant-`F` regression pin, the engine's state
propagation through the path). It is the next stage in the toolkit's
HANDOFF and the same extension Primiceri's TVP-VAR-SV needs (Chapter 5
§5). The idiosyncratic AR(1) components with SV are expressible as
states today but multiply the state dimension by the number of series;
the bridge below leaves them as iid measurement shocks.

## 3. The bridge model that runs today

The handbook's model with **constant** factor AR coefficients and
stochastic volatility on the factor shocks, on the handbook's own
generated panel (two countries, 40 series):

```python
# build_ch7.py — identification as in generate_data.m: unit loading blocks
measurement = ["c1_s1 = fw + e_c1_s1",
               "c1_s2 = l_c1_s2_fw*fw + fc1 + e_c1_s2",
               "c1_s3 = l_c1_s3_fw*fw + l_c1_s3_fc*fc1 + e_c1_s3", ...]   # 40 equations
transition  = ["fw = a1_fw*fw[-1] + a2_fw*fw[-2] + eta_fw",
               "fc1 = a1_fc1*fc1[-1] + a2_fc1*fc1[-2] + eta_fc1",
               "fc2 = a1_fc2*fc2[-1] + a2_fc2*fc2[-2] + eta_fc2"]
shocks = {"eta_fw": au.sv(sigma_h=0.2, h0_sd=1.0, mu_h0=0.0), ...,       # SV on the factor shocks
          "e_c1_s1": au.shock("se_c1_s1"), ...}                          # iid idiosyncratic shocks
```

The compiler derives six states (`fw, fw[-1], fc1, fc1[-1], fc2,
fc2[-1]`), three SV paths on the state side, forty measurement shocks;
`m = 40`, `n = 6`, `T = 220`. The 40×40 innovation Cholesky per period
makes this the slowest model in the companion; its run is a run session
(`09-run-sessions.md`), and the record is appended here when it lands.

What the bridge shows, and what it does not: the factor-volatility paths
— the handbook's `hlast0x` — are estimated with credible bands, and the
loadings and factor persistence with them; the drift in the factors'
persistence (`ρ_t`) is held constant, so the handbook's variance
decomposition *over time* (`vdecompwx`) is not reproduced. After E6 it
is: the bridge spec gains `a1_fw = a1_fw[-1] + ...` transition equations
for the coefficients and nothing else changes.

> **What differs from the handbook.** Two countries rather than four
> (compute); constant AR coefficients (E6); iid idiosyncratic shocks
> instead of AR(1)-with-SV (a state-dimension choice, not a class
> limit); the inverse-Wishart / inverse-gamma priors of §3 replaced by
> half-normal scales and `N(0, 1)` loadings; the principal-components
> starting values the handbook needs are not needed by NUTS.
